## 最初に読むこと：すでに作られているもの

**`ピースくん` + `island-ops.vercel.app` が稼働している。**ゼロからの自動化ではない。
以下は**すでに自動化済み**なので、作り直しを提案しないこと。

| 稼働中の機能 | 投稿先 |
|---|---|
| 訪問の振替・キャンセル・予定変更の通知 | `訪問看護_利用者スケジュール変更` |
| FAX 用紙の自動生成（URL 付き） | 同上 / `訪問看護_モニタリングアラート` |
| 新規受付の構造化と投稿 | `訪問看護_新規利用者管理` |
| モニタリング対象者の自動見直し | `訪問看護_モニタリングアラート` |
| モニタリング再調整の依頼投稿 | 同上 |
| 利用者連絡の未対応アラート | `訪問看護_利用者スケジュール変更` |
| FAX スキャンの担当ケアマネ別自動仕分け（1日3回・Google Drive） | `ケアマネ_全体` で告知済 |
| ジェノグラム作成 | `island-ops.vercel.app/carepan/genogram` |

**したがって巻き取り先は「未自動化の業務」ではなく、「自動化が止まった先で人が拾っている部分」。**

## 巻き取り候補（優先順）

### 1. 利用者ごとの制約の構造化 ★本命

**問題**: デイの曜日、リハの時間、訪問頻度の取り決めといった制約が、**スタッフの頭と Slack の投稿の中にしかない。**システムが知らないので自動調整が毎回衝突し、人が毎回訂正している。

根拠となる発言:

> 松岡成治様 ６月から月曜日いづみの里のデイを利用開始していまして、8/24モニタリング設定されていますが難しいと思います。月曜日デイ、金曜日リハ9:30以外での設定をお願いいたします
> — 門脇, `モニタリングアラート`, 2026-08-14

> 佐々木様7月のモニタリングの際に次回2ヶ月おき、その後状態安定していれば3ヶ月おきと話をされていました。8月モニタリングなし、次回9月となっています。
> — 門脇, 同, 2026-08-17

> ・自動で日程調整かけるとき休憩時間が考慮されておらず、休憩時間にぶち込まれる
> ・モニタリング手動入力時にリハの時間と被って組んでしまう事が時々あり。ここどうにかしたい
> — 高野, DM, 2026-08-14

新規受付の相談内容にも自然文で埋まっている:

> 高校の集中スクーリングが8/21〜8/27なので8/28以降、9月ころで無いとお母様も動けない
> 克宏様の前の時間になるように調整お願いします
> デイサービス休み期間は週に2回、デイサービス再開後は週に1回程度

**やること**: 自然文の制約を構造化して蓄積し、調整時に参照させる。効果は最大だが設計が要る。

`訪問看護_加算管理` はピースくんが一切関与しておらず、全て人の投稿。

> 【小杉 敏雄 様】　要支援で1年経過 R8.7月から12か月越え減算になります。

**12ヶ月越え減算は日付計算だけで自動判定できる。**人が気づいて投稿する必要がない。

> 小松優子様の複数名加算について確認お願いします。
> ※訪問時間が重複しており、時間調整必要です。加算取るところを教えてほしいです

### 4. 未対応アラートの追跡

アラートは鳴るが、誰が拾うかが決まっていない。

> 📞 利用者連絡の未対応があります（2026-08-20）
> ・長谷川　建治 様 [未連絡 / 振替] … 連絡先: **連絡先未選択**

鳴らすだけでなく、拾われるまで追う仕組みが要る。
